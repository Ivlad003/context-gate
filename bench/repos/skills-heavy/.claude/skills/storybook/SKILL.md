# storybook

1. Прочитай файли, яких стосується задача.
2. Дотримуйся умовностей групи web: імена, структура, тести поряд.
3. Перед завершенням запусти перевірки пакета і коротко опиши, що змінено.

Приклади, антипатерни і чекліст рев'ю для storybook — у розділах нижче; читай їх лише за потреби.
